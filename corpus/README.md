# neurotic-docx-bench fixtures

Source fixtures of the neurotic-docx-bench benchmark: input DOCX files and the
Microsoft Word oracle renders they are scored against. Every file is listed in
`MANIFEST.sha256.json` with its sha256; `bench fixtures download` refuses a snapshot
that does not match it.
