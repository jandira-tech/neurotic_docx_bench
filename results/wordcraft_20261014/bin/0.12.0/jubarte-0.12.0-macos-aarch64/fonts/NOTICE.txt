Copy these fonts into $JUBARTE_FONT_DIR, or into the per-user
jubarte fonts directory (scripts/install.sh --fonts-only does
this from a source checkout):
  macOS   ~/Library/Application Support/jubarte/fonts
  Linux   $XDG_DATA_HOME/jubarte/fonts (default ~/.local/share/jubarte/fonts)
