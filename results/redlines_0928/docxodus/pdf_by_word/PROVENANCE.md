# Made by Microsoft Word from docxodus redlines

Every file in this folder was produced by **Microsoft Word 16.114 (16.114.26092233) via scripts/word_pdf.py**, not by docxodus.

- Redline tool: docxodus 12.6.4
- Source redlines: `docxodus/docx/` (the DOCX files docxodus generated)
- What Word did: opened the redline DOCX in Word and exported it to PDF
- Driver: `scripts/word_pdf.py` (one osascript per batch)
- Files: 1065 PDF, 0 DOCX

The PDFs carry no Word marker in their metadata: Word for Mac exports through macOS, so the PDF Producer reads `Quartz PDFContext`. `provenance.csv` lists each file with its source DOCX, both sha256 values and the PDF Producer and creation date.
