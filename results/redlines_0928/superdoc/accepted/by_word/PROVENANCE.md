# Made by Microsoft Word from superdoc redlines

Every file in this folder was produced by **Microsoft Word 16.114 (16.114.26092233) via scripts/word_pdf.py**, not by superdoc.

- Redline tool: superdoc-sdk 2.15.0
- Source redlines: `superdoc/accepted/src/` (the DOCX files superdoc generated)
- What Word did: opened the redline DOCX in Word, accepted all tracked changes, saved the DOCX, exported it to PDF
- Driver: `scripts/word_pdf.py` (one osascript per batch)
- Files: 5 PDF, 5 DOCX

The PDFs carry no Word marker in their metadata: Word for Mac exports through macOS, so the PDF Producer reads `Quartz PDFContext`. `provenance.csv` lists each file with its source DOCX, both sha256 values and the PDF Producer and creation date.
