## 4. One-liners: jubarte PDFs of the documents, no redlines

The bench resolves the jubarte binary from `--converter`, then `JUBARTE_BIN`, then
`../jubarte-redlines/target/release/jubarte`, then PATH and `~/.cargo/bin`
(`docx_to_pdf.resolve_tool_binary`). It calls it as
`jubarte convert <docx> -o <pdf> --force` (`docx_to_pdf._convert_command`). The
one-liners below use the same shape; set `JUBARTE_BIN` if the binary is elsewhere.

Render every document of the new corpus (documents only; `documents.csv` has no
comparison rows) into `runs/jubarte-pdf/<state>/<stem>_jubarte.pdf`, 8 at a time:

```bash
cd /Users/arthrod/temp/T/neurotic_docx_bench && J=${JUBARTE_BIN:-../jubarte-redlines/target/release/jubarte} && python3 -c 'import csv;[print(r["docx"]) for r in csv.DictReader(open("corpus/word/documents.csv"))]' | xargs -P 8 -I{} sh -c 'd=runs/jubarte-pdf/$(dirname $(dirname {})); mkdir -p "$d"; "$0" convert "corpus/word/{}" -o "$d/$(basename {} .docx)_jubarte.pdf" --force' "$J"
```

Only the clean documents:

```bash
cd /Users/arthrod/temp/T/neurotic_docx_bench && J=${JUBARTE_BIN:-../jubarte-redlines/target/release/jubarte} && mkdir -p runs/jubarte-pdf/clean && ls corpus/word/clean/docx/*.docx | xargs -P 8 -I{} sh -c '"$0" convert "{}" -o "runs/jubarte-pdf/clean/$(basename {} .docx)_jubarte.pdf" --force' "$J"
```

Score jubarte against the Word PDFs on the existing no-redline track (the pinned
`corpus/word_based` `docx_source`/`pdf_source` pools; this is the track that exists
today, the `corpus/word` track is item 3 above):

```bash
cd /Users/arthrod/temp/T/neurotic_docx_bench && uv run bench docx-to-pdf --tool jubarte --track docx_to_pdf_no_redline_docs --json results/docx_to_pdf_no_redline_jubarte-$(git -C ../jubarte-redlines rev-parse --short HEAD).json --work-dir results/docx_to_pdf_work
```

Add `--converter /path/to/jubarte` to pin a build, `--limit 20` for a smoke run,
`--no-resume` to re-render candidates that already exist under `--work-dir`.
