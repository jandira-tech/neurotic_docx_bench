- Consolidate the old superdoc benchmarks (the 'harness' benchmark) and the docxide benchmark into one, by merging them, maintaining its numeric result
- Officially add a penalty for documents that failed (but for a small corpus make it smaller to not pollute the record)
- Add a few preliminary pass-fail rubrics that could be quicker, among others: (1) for docx files, whether the full content of both documents present or tossed, (2) because many tools delete insertions, deletions, comments, make one `lax` as default, but don't make this specific content pass or fail as default (but add a `include-comments` too), (3) similarly to pdfs, a fuzzy threshold of both documents, `lax` or `strict`, (4) placement is text in the correct location (default is also `lax` but if comments point to the wrong part of the text, make it fail in `include-comments`)
- Make the rubric configurable, add the defaults to each run (for people who prefer other visualization tools), e.g. merge pages or not (bench one gigantic page if permitting), text placement, colours/contrast, remove images (possible?)
